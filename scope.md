# ReceiptRelay — scope

## Problem
Receipts contain dates that matter, but the useful information is buried in noisy text. People miss return windows and warranty checkpoints.

## User
A person who wants a quick, private answer after buying something.

## One end-to-end job
Paste receipt text → extract merchant, total, purchase date, return/warranty clues → show dated next steps with evidence and confidence.

## In scope
- Browser-local receipt text input
- Sample receipt for instant demo
- Date, amount, return-window, and warranty pattern detection
- Evidence text beside each result
- Responsive, accessible interface

## Out of scope
- Uploading images or receipts
- Cloud storage or accounts
- Real legal/retailer policy verification
- Automated claims, reminders, or purchases

## Success
A first-time user can paste a receipt and understand the next useful action in under one minute.
